- Figma 없이 로컬 정적 서버에서 `/`, `/stores`, `/guide` 실행.
- 홈 → 지점 찾기 → 이용 안내 → 지점 찾기 이동 및 마곡 검색 상태 복원.

- 320px / 390px / 834px / 1440px에서 홈페이지 가로 넘침 없음.

## 범위와 한계

- 실제 회사 서버에 업로드하거나 도메인을 변경하지 않았습니다.
- 실제 iPhone/Android 기기나 카카오톡 앱에서 방 참여·주문·결제는 실행하지 않았습니다.
- 지점 주소/채팅방 미등록 항목은 추측하지 않고 비워 두었습니다. `store-link-audit.json` 참조.
- 안내 화면의 캡처는 Figma 원본과 동일한 과거 예시입니다. 새 지점 수로 캡처 이미지를 재작성하지 않았습니다.
- 화면 캡처와 동작 확인 기록은 상위 `verification/`에 있습니다.
