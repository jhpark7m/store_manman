# 콘텐츠 출처와 원본 기록

- Figma 파일: https://www.figma.com/site/upOICX8Waro7PtRH36TOMX/
- 기존 공개 사이트: https://bit-groove-42091164.figma.site/
- 원본 코드 12개를 Figma Make 편집기에서 전체 선택·복사로 추출했습니다. 파일별 SHA-256은 `source-provenance.json`에 있습니다.
- 코드에 포함된 이미지 데이터는 재인코딩 없이 원래 이미지 바이트로 분리했습니다. 외부 로고·사진은 기존 코드의 원본 주소에서 내려받았습니다. URL과 SHA-256은 `assets-manifest.json`에 있습니다.
- 품질 카드 사진 3장은 이전 제작 단계에서 AI로 선명도와 가로 구도를 보정한 이미지입니다. 새로운 현장 촬영 사진으로 설명하지 않습니다.
- 후기 원문·점포 페이지 출처는 홈페이지 소스에 보존되어 있습니다. 기존 원본 주석의 언론사 사진 재사용 허락 범위·후기 공개 재사용 동의 미확인 기록도 유지했습니다.
- Paperlogy: https://github.com/fonts-archive/Paperlogy / 배포 안내 사본은 `licenses/Paperlogy-README.md`입니다. 원래 글꼴을 수정하지 않았습니다.
- React / React DOM의 MIT 라이선스는 `licenses/`에 포함되어 있습니다. 회사 콘텐츠나 사진 전체에 MIT 라이선스를 적용한다는 뜻은 아닙니다.
