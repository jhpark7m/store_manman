# 만만마켓 히어로 섹션 · 회사 전달용

2026-10-24 기준, 롤백 후 유지한 B안 히어로만 추출했습니다.
기존 홈페이지 헤더, 만만마켓 소개, 매장 사진, 후기, 이용 방법, 푸터는 포함하지 않았습니다.
Figma 초안이나 운영 사이트에는 이 전달 작업으로 인한 변경·게시를 하지 않았습니다.

## 바로 확인하기

압축을 푼 뒤 `index.html`을 브라우저로 열면 히어로만 확인할 수 있습니다.
별도 설치나 빌드가 필요 없습니다. 브라우저 폭을 줄여 모바일 배치도 볼 수 있습니다.
기존 사이트의 헤더는 포함하지 않았으므로, 실제 페이지에서는 헤더 높이가 추가됩니다.

## 구성

- `index.html`: 단독 미리보기. HTML·CSS·JS를 그대로 연결한 실행본
- `hero-section.html`: 기존 페이지에 삽입할 히어로 마크업만
- `hero.css`: 격리된 스타일과 반응형 규칙
- `hero.js`: 모바일·태블릿 순환 애니메이션, 키보드 조작
- `preview/`: PC·모바일 표시 참고 이미지
- `assets/`: 실제 상품 이미지 3장. 기존 초안에서 사용한 이미지 파일

## 개발팀 적용 방법

1. `hero.css`, `hero.js`, `assets/`를 사이트에 복사합니다.
2. 기존 홈페이지 헤더 바로 아래에 `hero-section.html`의 내용을 삽입합니다.
3. 페이지 head에 다음 두 줄을 추가합니다. 실제 배포 위치에 맞춰 경로를 조정합니다.

```html
<link rel="stylesheet" href="/경로/hero.css">
<script src="/경로/hero.js" defer></script>
```

4. 이미지의 `src="assets/..."` 경로를 실제 배포 경로에 맞춥니다.
5. CTA의 `href="/stores"`를 회사 사이트의 지점 선택 주소로 확인·설정합니다.
   단독 미리보기 파일에는 지점 페이지가 없으므로 CTA 목적지는 열리지 않습니다.
   Figma 전용 라우팅 코드는 제거했습니다. 일반 웹 링크로 연결됩니다.

클래스는 `.mmh-root` 아래로 범위를 제한했습니다. 기존 사이트 전체의 스타일을 덮어쓰지 않습니다.
히어로의 폭에 따라 반응하며, 데스크톱 기준은 브라우저 폭이 아닌 히어로 컨테이너 폭 1200px입니다.
동일 페이지에 여러 개 삽입한다면 `mm-b-title`과 `aria-labelledby`를 서로 일치하는 고유 ID로 바꾸세요.
React/Vue 등에서도 HTML을 해당 템플릿 문법으로 옮길 수 있습니다. 동적 삽입 시
`const destroy = window.ManmanHero.mount(rootElement)`를 호출하고 제거 시 `destroy()`를 호출하세요.
원본 Figma 컴포넌트에 대한 의존성이나 별도 JavaScript 라이브러리는 없습니다.

## 유지한 디자인·동작

- 제목: “이 가격, 이미 끝났습니다.” / “이미 끝났습니다.”는 빨간색
- 컬러 상품 이미지, “공동구매 종료” 스티커, 가격 옆 “종료” 표시
- 비교가격에만 취소선 적용, 종료 특가에는 취소선 없음
- “하지만, 끝난 건 이 특가뿐입니다.”
- “매일 달라지는 새로운 공동구매. 다음 혜택은 놓치지 마세요.” 강조
- “오늘의 공동구매 확인하기 →” CTA와 지점 안내
- 컨테이너 1200px 이상: 상품 3개 고정 가로 배치
- 1200px 미만: 감자탕을 먼저 전면에 표시, 3초마다 다음 상품으로 순환
- 전환 시간 1.2초. 운영체제의 동작 줄이기 설정에서는 자동 순환·이동 없음
- 리뷰용 구분띠, 흑백/컬러 선택, 검토중 표시, 원본 이미지 보기, 일시정지 버튼은 제외

## 이미지와 폰트

이미지는 초안에 쓰인 상품 사진 파일 그대로입니다. 전체 판매 안내 원본은 포함하지 않았습니다.
화면과 동일한 크롭은 CSS에 들어 있습니다.
Paperlogy 서체는 기존 초안과 같은 외부 CSS 주소로 불러옵니다.
인터넷 연결 또는 CDN 접근이 없으면 시스템 한글 서체로 표시되어 줄바꿈·굵기가 달라질 수 있습니다.
회사 배포 환경에서는 회사의 서체 관리 방식에 맞춰 자체 호스팅 경로로 교체할 수 있습니다.
